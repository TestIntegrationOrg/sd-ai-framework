# PowerShell Engineering

Respect the repository's PowerShell version and host assumptions, approved execution policy/signing model, parameter validation, terminating/non-terminating error behavior, exit codes, pipeline semantics, security boundaries, logging, and Pester conventions. Avoid unsafe string execution and silent error suppression. Do not relax signing/execution controls or version requirements without explicit approval.
