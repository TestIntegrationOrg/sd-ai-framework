# Spring Boot

Use the Spring Boot version and Java baseline already present in the repository. Preserve established configuration, dependency injection, API/error handling, observability, security, and test conventions. Prefer framework-supported mechanisms over custom infrastructure. Do not migrate Spring Boot, Java, build plugins, or dependency families unless the approved change explicitly requires it. Verify focused unit/integration behavior before completion.
