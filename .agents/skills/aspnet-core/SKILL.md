# ASP.NET Core

Preserve the repository's ASP.NET Core and target-framework boundaries. Follow established middleware, dependency injection, configuration, authentication/authorization, API validation, problem-details/error handling, logging, cancellation, and test patterns. Prefer framework-native features and existing packages. Do not change target frameworks or package families unless explicitly approved.
