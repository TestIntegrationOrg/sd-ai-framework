# Python Engineering

Use the repository's Python compatibility constraint, packaging/build tooling, typing conventions, dependency-management approach, logging/error handling, and test stack. Prefer clear typed interfaces and deterministic resource/error behavior where the codebase supports them. Do not silently change supported Python versions or dependency constraints. Keep changes focused and verify with the repository's existing tests and linters.
