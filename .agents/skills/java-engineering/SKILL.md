# Java Engineering

Use repository technology evidence as the compatibility boundary. Follow the existing Java version, build tool, dependency conventions, package structure, error handling, observability, and test stack. Prefer idiomatic APIs available in the detected/pinned Java version. Make the smallest approved change, preserve security controls, test affected behavior, and never introduce a major-version or dependency migration without explicit approval.
