# C# Engineering

Respect independently detected C# language and .NET runtime/framework versions. Follow the repository's project structure, dependency injection, async/cancellation, nullability, error handling, logging, package management, and test conventions. Use APIs supported by the pinned target frameworks and language version. Keep changes narrow and do not upgrade .NET, SDKs, or NuGet dependencies without approval.
